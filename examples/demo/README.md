# Demo inputs

Synthetic, tiny, and safe to commit — used by the quickstart and tutorials.

| File | What it is |
|---|---|
| `expr.tsv` | tidy table (48 rows): genotype × condition × time, expression and OD |
| `paper.pdf` | a 4-page generated PDF with one bar-chart figure and caption (for `ingest`) |
| `figure.py` | the paper's figure script (matplotlib), used by the reproduce tutorial |
| `figure.R` | the same figure in ggplot2 |
| `figure-source.png` | the paper figure image referenced by the manifest |

These are generated fixtures, not real research data. The PDF and PNG are regenerated by
`tests/pdf_fixture.py`; the table is hand-written synthetic values.
