# 教程

六节教程对应 gaxis 的两条主流程和三项支撑能力。每节都能独立执行，按顺序做效果最好。

| 节 | 你会得到什么 | 需要网络 | 需要 KB |
|---|---|---|---|
| [01 第一张图](01-first-figure.zh.md) | 一张期刊图 + 可编辑脚本 + manifest | 否 | 否 |
| [02 需求/数据 → 选图](02-plan-and-select.zh.md) | 候选图、contact sheet、选择记录 | 否 | 是 |
| [03 模板适配](03-adapt-template.zh.md) | 用新数据复用验证过的模板代码 | 否 | 是 |
| [04 论文复现 → 代码入库](04-reproduce-paper.zh.md) | L1/L2/L3 评级、代码资产、可检索页面 | 是 | 是 |
| [05 多面板拼版](05-compose-panels.zh.md) | 一页矢量多面板图 + 合成 manifest | 否 | 否 |
| [06 运维](06-operations.zh.md) | 自动入库队列、定时任务、自愈检查 | 是 | 是 |
| [08 AMR 共现网络](08-amr-network.zh.md) | 表 → 共现边 → 画网络图，不重跑 AMR | 否 | 否 |
| [09 SNP 树工作流](09-snp-tree-workflow.zh.md) | IQ-TREE 的 Snakemake 脚手架与校验，由 bacmap 执行 | 否 | 否 |

## 建议的练习顺序

```text
01 ──► 02 ──► 03 ──► 05          （完全离线，先建立直觉）
          └──► 04 ──► 06          （接真实论文时再做）
```

## 每节都有的结构

- **目标**：做完能验证什么；
- **命令**：可直接复制；
- **你应该看到**：正常输出长什么样；
- **检查点**：用文件/manifest 字段自查，而不是"看起来对"；
- **常见问题**：失败时先看这里。

!!! tip "先跑 `pixi run check`"
    教程假设仓库当前状态是绿的（ruff/mypy/pytest 全过）。如果有失败，先修好再往下走，
    否则你分不清是新问题还是环境问题。
